## How to Turn OpenStick Debian into an OpenWrt-Style 4G Router in 60 Seconds

Once you flash **OpenStick Debian** using the [1-Click Installer](/boards/uz801/flashing/#method-1-automated-1-click-openstick-installer-recommended), you can configure a 4G LTE cellular WAN connection and broadcast a Wi-Fi hotspot using standard `nmcli` commands:

```bash
# 1. SSH into your OpenStick dongle over USB
ssh user@192.168.5.1

# 2. Enable the 4G LTE modem and connect to your carrier APN
sudo mmcli -m 0 --enable
sudo nmcli connection add type gsm ifname cdc-wdm0 con-name "4G-WAN" apn "internet"
sudo nmcli connection up "4G-WAN"

# 3. Create a Wi-Fi Access Point (Travel Router Hotspot) with NAT sharing
sudo nmcli device wifi hotspot ifname wlan0 ssid "OpenStick-4G" password "MySecurePassword123"
```

NetworkManager automatically handles DHCP (`dnsmasq`), IPv4 packet forwarding, and `nftables`/`iptables` NAT masquerading between the 4G LTE modem (`wwan0`), the Wi-Fi hotspot (`wlan0`), and the USB Ethernet interface!

Want a web dashboard like OpenWrt's LuCI? Because you're running full Debian, you can install **Cockpit** (`sudo apt install cockpit`), **RaspAP**, **Pi-hole**, or **AdGuard Home** directly via `apt`.
