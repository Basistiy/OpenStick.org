## Featured Community Builds

### 1. Mini Linux Cyberdeck Running DOOM

Created by [@glos-os](https://www.youtube.com/@glos-os), this build transforms a €20 4G LTE pocket modem (Qualcomm Snapdragon 410) with an integrated color SPI screen into a standalone retro-gaming cyberdeck.

- **OS**: Debian GNU/Linux ARM64 via OpenStick
- **Display**: Built-in 1.44" color SPI TFT
- **Control**: Mechanical keyboard connected over USB OTG
- **Software**: Chocolate Doom / PrBoom running full speed on battery

### 2. Battery-Powered USB Host Mode & 5V Booster Mod

Standard modem motherboards run in USB device (gadget) mode and lack 5V VBUS power rail generation when running off the 3.7V battery.

This hardware modification by [@glos-os](https://www.youtube.com/@glos-os) adds an **MH-CD42 step-up boost converter** and a power switch to supply clean 5V power to the USB port, enabling USB keyboards, mice, flash storage, and microphone receivers.

### 3. Glosos: Open-Source Cellular Voice AI Handheld

A budget-friendly €20 alternative to Meta's prototype "Muse Charm" AI handheld:

- Uses a Qualcomm Snapdragon 410 4G modem running mainline Linux via OpenStick.
- Streams voice bi-directionally over 4G LTE using low-latency WebRTC directly to a private Mac.
- Local speech-to-text (STT), LLM intelligence, and local speech synthesis (TTS) keep all personal data safe at home with zero vendor subscription markup.

## Want to Showcase Your Project Here?

Adding your project to OpenStick.org takes less than 5 minutes!
1. Click **"Edit this page"** at the bottom of the page or create a markdown file in `src/content/docs/projects/`.
2. Include a summary, hardware requirements, and links to your GitHub repo or YouTube build video.
3. Submit a Pull Request!
