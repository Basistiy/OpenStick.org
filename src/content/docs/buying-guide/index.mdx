Finding genuine **Qualcomm Snapdragon 410 (MSM8916)** 4G USB modems online can be tricky. Because many generic manufacturers reuse the same plastic outer enclosures, sellers on AliExpress, Taobao, and eBay frequently substitute non-Qualcomm chips (**ASR1802**, **ZX297520**) or incompatible **SPI-NAND flash** without updating the listing title.

This community buying guide maintains **tested, verified store links** where OpenStick community members have successfully purchased genuine Qualcomm MSM8916 hardware with eMMC storage.

## ⚠️ Key Rules Before Buying

<CardGrid>
  <Card title="1. Confirm with the Seller" icon="chat">
    Ask the seller directly if the device uses Qualcomm Snapdragon 410 (MSM8916) with eMMC flash storage before ordering. Written confirmation in chat makes dispute refunds straightforward if a non-Qualcomm board is delivered.
  </Card>

  <Card title="2. Confirm eMMC (Not NAND)" icon="warning">
    Ensure the board has **eMMC 4GB / 8GB** storage (smooth square BGA chip). Standard OpenStick Debian and mainline Linux kernel images **do not** boot on raw SPI-NAND flash.
  </Card>

  <Card title="3. Beware of Suspiciously Cheap Clones" icon="error">
    Listings priced unusually low are almost universally cost-reduced ASR1802 or ZX297520 clones that cannot run Linux.
  </Card>

  <Card title="4. Test Before Confirming Receipt" icon="approve-check">
    When your package arrives, pop open the shell to inspect the silkscreen and run `adb shell getprop ro.board.platform` before clicking "Confirm Order Received".
  </Card>
</CardGrid>

## Community Guidelines for Submitting Links

To maintain high data quality and protect community members from scams, all submitted store links must meet these criteria:

1. **Clean Product URLs**: Strip all personal tracking and referral parameters (remove `?spm=...`, `&scm=...`, `&_gl=...`, etc.). Use clean canonical URLs (e.g. `https://www.aliexpress.com/item/1005012883269576.html`).
2. **Motherboard & Silkscreen Verified**: You must open the plastic enclosure and inspect the PCB silkscreen (e.g. `UZ801_V3.31`, `UZ801_V3.0`, `HM-MIFIB_V18`).
3. **SoC & Memory Confirmed**: Provide software verification output from stock Android ADB:
   ```bash
   adb shell getprop ro.board.platform
   # Output must be: msm8916
   ```
4. **No Affiliate Loops or URL Shorteners**: Links through link-shorteners or suspicious redirect services will be resolved to their canonical product URL.
5. **Report Chip Swaps**: If a seller previously listed on this page starts shipping non-Qualcomm chips, please [open an issue](https://github.com/Basistiy/OpenStick.org/issues/new) immediately so we can update the status badge to 🔴 **Chip-Swap Warning**.
