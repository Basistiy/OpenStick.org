## Verification Checklist

Before submitting a purchase link, ensure you have verified the following details on your received modem:

<Steps>
1. **Clean Product URL**:
   Remove all tracking parameters from the web shop link.
   - ❌ Bad: `https://www.aliexpress.com/item/1005001234567890.html?spm=a2g0o.productlist.0.0.1234&pdp_npi=4...`
   - ✅ Good: `https://www.aliexpress.com/item/1005001234567890.html`

2. **Inspect the Physical PCB Silkscreen**:
   Pop open the plastic snap-on case with a plastic pry tool or guitar pick. Note the printed text:
   - Examples: `UZ801_V3.0`, `HMUF02-V05`, `UFI003_MB_V02`, `UFI001B_MB_V02`

3. **Verify Chipset via ADB (Stock Android Firmware)**:
   Connect to the modem via USB or Wi-Fi (enable USB debug via `http://192.168.100.1/usbdebug.htm` or `http://192.168.43.1/usbdebug.htm` if required):
   ```bash
   adb devices
   adb shell getprop ro.board.platform
   ```
   - Must output: `msm8916`
   - If output is `asr1802`, `zx297520`, or `sp9820e`, **do not submit as a working link!** (Instead, submit a scam/chip-swap warning).

4. **Verify Storage (eMMC vs NAND)**:
   ```bash
   adb shell ls -l /dev/block/bootdevice/by-name
   ```
   If standard partitions (`boot`, `system`, `modem`, `userdata`, `fsg`) exist as block devices, the unit is confirmed **eMMC**.

5. **Verify RAM (Especially for UFI003 1GB claims)**:
   ```bash
   adb shell cat /proc/meminfo | grep MemTotal
   ```
   - Standard boards: `~480000 kB` (512 MB)
   - Genuine UFI003: `~980000 kB` (1 GB)
</Steps>

## Markdown Table Row Template (For Pull Requests)

If you are submitting via a Pull Request to `src/content/docs/buying-guide/index.mdx`, use the following markdown template row for your board's table:


## Status Badges Reference

When adding or updating listings, use one of the following badges:

| Status | Badge Code | When to Use |
| :--- | :--- | :--- |
| **Confirmed Working** | `<Badge text="Confirmed" variant="success" />` | Hardware tested and verified with MSM8916 + eMMC within the last 6 months. |
| **Caution / Mixed** | `<Badge text="Caution" variant="caution" />` | Seller sometimes ships alternate revisions; buyers must message seller beforehand. |
| **Chip-Swap Warning** | `<Badge text="Chip Swap" variant="danger" />` | Seller previously sold MSM8916 but has silently switched inventory to ASR or ZXIC. |
| **Out of Stock** | `<Badge text="Sold Out" variant="note" />` | The listing has expired, is no longer active, or the store closed. |
