## 4. Hardware Modifications & Cyberdeck Builds

### Linux on €20 4G Modem: Adding USB Host Mode & 5V Booster

Upgrading a cheap €20 4G LTE USB modem powered by Qualcomm Snapdragon 410 (MSM8916) into a fully portable, battery-powered Linux computer using OpenStick:

- **The Problem**: While the MSM8916 chipset supports USB host mode, the stock board lacks a 5V power line on the USB port (VBUS) when running on battery.
- **The Mod**: Adding an **MH-CD42 step-up boost converter** to supply 5V to the USB VBUS rail directly from the 3.7V battery.
- **Power Switch**: Installing a power toggle switch on the 5V booster output to prevent current collision between the charger and the booster.
- **Result**: Boots full desktop Linux (Debian ARM64) on battery power, supports external displays, and allows connecting USB keyboards, gaming peripherals to play DOOM, and even a DJI Mic receiver to interact with AI agents.
