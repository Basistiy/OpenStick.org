The **UFI003** is an MSM8916-based 4G USB dongle distinguished by a convenient **hardware push button for instant EDL 9008 recovery** and an onboard IPEX antenna socket.

Like other standard OpenStick boards, factory retail UFI003 boards feature **512 MB of LPDDR3 RAM** and **4 GB of eMMC storage**. 

---

## Hardware Specifications

| Component | Specification |
| :--- | :--- |
| **SoC** | Qualcomm Snapdragon 410 (MSM8916) 4x Cortex-A53 @ 1.2 GHz 64-bit |
| **RAM** | **512 MB LPDDR3** (Standard retail board) |
| **Storage** | **4 GB eMMC 5.0** (Standard retail board) |
| **Wireless** | Qualcomm WCN3620 (802.11b/g/n 2.4 GHz + Bluetooth 4.0) |
| **Cellular Modem** | Qualcomm LTE Cat 4 (B1, B3, B5, B7, B8, B20, B38, B40, B41) |
| **Hardware Button** | Onboard SMD push button for instant EDL 9008 recovery |
| **Power Input** | USB-A 5V, ~300mA idle, up to 1.2A peak LTE load |

## Beware of Fake "1GB" Listings (The Myth vs. Reality)

:::danger[Scam Alert: Fake 1GB Listings]
Because online listings frequently advertise the UFI003 as "1GB RAM / 8GB ROM" or "1G+8G" at inflated prices ($12–$16 USD compared to $6–$8 for standard dongles), buyers often expect double the memory. 

**No factory-manufactured 1GB UFI003 has been verified in the community.** Testing retail units consistently confirms they are standard **512MB RAM / 4GB eMMC** devices, occasionally with firmware spoofing Android property values to show "1GB".
:::

### Where did the 1GB claim come from?
1. **Deceptive Seller Marketing**: Chinese e-commerce vendors commonly use "1G+8G" or "1GB" in listing titles as keyword stuffing or false advertising.
2. **DIY BGA Chip Swaps ("换字库")**: In maker and modding forums (CoolApk, Tieba), enthusiasts have hand-soldered replacement BGA162 eMCP chips (such as the *Samsung KMQE60013M* 1GB+8GB or Micron chips) onto UFI003 boards using hot-air rework stations. These are custom one-off hardware mods, not factory retail products.

## Silkscreen & Identification

Inside the plastic casing:
- Look for the text **`UFI003_MB_V01`** or **`UFI003_MB_V02`**.
- An SMD tactile push button is mounted near the edge of the RF shielding can.
- Standard factory boards feature a 512MB RAM / 4GB eMMC eMCP package.

---

## Post-Purchase Verification

When your stick arrives, plug it into your computer and verify the actual physical memory:
```bash
adb shell cat /proc/meminfo | grep MemTotal
# Factory UFI003 boards report ~480000 kB (512 MB)
```

If a seller charged a premium claiming 1GB RAM, you can use the output above to request a partial refund or dispute for false advertising.
