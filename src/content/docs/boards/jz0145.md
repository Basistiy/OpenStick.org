The **JZ0145** (commonly referred to as the **XiaoXun JZ0145** or **JZ01-45**) is a community-discovered 4G LTE USB modem family powered by the Qualcomm Snapdragon 410 (MSM8916). 

While often sold in identical generic plastic white-stick enclosures as the UZ801 or UFI001, it features a distinct PCB layout, different test point locations, and specialized unbrick firmware images.

---

## Hardware Specifications

| Component | Specification |
| :--- | :--- |
| **SoC** | Qualcomm Snapdragon 410 (MSM8916) 4x Cortex-A53 @ 1.2 GHz 64-bit |
| **RAM** | 512 MB LPDDR3 |
| **Storage** | 4 GB eMMC 5.0 (BGA chip, typically SK Hynix) |
| **Wireless** | Qualcomm WCN3620 (802.11b/g/n 2.4 GHz + Bluetooth 4.0) |
| **Cellular Modem** | Qualcomm LTE Cat 4 (B1, B3, B5, B7, B8, B20, B38, B40, B41) |
| **SIM Slot** | Standard push-slide Micro-SIM (3FF) metal cage |
| **Recovery Button** | Onboard SMD tactile recovery switch near SIM slot (certain revisions) |
| **Power Input** | USB-A 5V, ~250mA idle, up to 1.0A peak LTE load |

## Flashing & Community Firmware

The automated 1-Click OpenStick installer does not yet natively support all JZ0145 revisions out of the box. However, community members have verified working methods using dedicated repositories:

### 1. XiaoXun JZ0145 Debian Unbrick & Installer
For devices stuck in EDL or requiring custom rootfs installation:
* **Repository**: [NguyenPhat-NT/XiaoXun-JZ0145-Debian-Unbrick](https://github.com/NguyenPhat-NT/XiaoXun-JZ0145-Debian-Unbrick)
* Contains pre-built partition tables, boot images, and scripts specifically adjusted for JZ0145 hardware.

### 2. OpenStick Custom Port
* **Repository**: [DRCRecoveryData/JZ01-45-Openstick](https://github.com/DRCRecoveryData/JZ01-45-Openstick)
* Community build files and device tree tweaks for the JZ01-45 board.

### 3. OpenWrt All-in-One Installer
* **Repository**: [aipmy/msm8916-4g-dongle-openwrt](https://github.com/aipmy/msm8916-4g-dongle-openwrt)
* Supports JZ0145 boards via web debug activation (`http://192.168.100.1/usbdebug.html`).

## Entering Qualcomm EDL Mode (9008)

To flash or unbrick a JZ0145 device:

1. **Software Method (If ADB is working)**:
   ```bash
   adb reboot edl
   ```
2. **Hardware Button Method**:
   * On revisions equipped with an SMD button near the SIM tray, hold down the button with a plastic probe while inserting the modem into your USB port.
   * Hold for 2–3 seconds, then release.
3. **Hardware Test Point Method**:
   * If no button is present, locate the test pads marked `BOOT` or `DP` / `GND` on the edge of the board.
   * Short `BOOT` to `GND` with tweezers while plugging into USB.
4. **Verification**:
   ```bash
   lsusb | grep 05c6:9008
   # Expected: Qualcomm, Inc. Gobi Wireless Modem (QDL mode)
   ```

:::tip[Always Back Up Partitions First!]
Before flashing any image, take a complete partition backup with [bkerler/edl](https://github.com/bkerler/edl) or `qdl`. JZ0145 uses Sahara HWID `007050e100000000` with PK_HASH `cc3153a80293939b`. Ensure you keep your modem calibration partitions (`modemst1`, `modemst2`, `fsg`) safe.
:::
